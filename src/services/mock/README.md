# mock 数据目录（已废弃）

## 状态

本目录下全部 mock 数据已**暂时废弃，以后不再使用**，各文件头部均已加 `@deprecated` 注释。

## 背景

后端接口已统一（收益端标签等字段由接口直接下发，如 `bizChannelLabel`），mock 数据不再维护，也不再与真实接口口径保持同步。

## 约束

- 禁止新增 mock 文件或在业务代码中继续引用本目录数据。
- 禁止重新开启 `src/config/index.js` 中的 `config.useMock`（当前为 `false`）。
- 新功能、新字段一律直接对接真实接口，不得再走 mock 分支。
- 保留本目录仅为历史追溯，后续确认无依赖后可整体删除。
