# 首页层级修正与剩余模块 Mock 交接

日期：2026-10-22。本记录覆盖本轮实现与复核，优先于上一批“批发商首页展示16个入口”的说明。

## 本轮用户指令

批发商最高等级首页仅有五个主功能；允许其余模块用假数据跑通交互，不需要在用户界面额外标注测试模式，但必须在代码保留清晰标记。所有页面继续参考蓝湖静态导出并适配机型。素材模板、等级权益正文仍留空，由客户后台维护。

## 已实现

- 批发商首页严格保留收益、上级、分享码、素材库、全球奖。经验/晋升放等级卡，团队/进货/划转放统计卡；购买VIP、活动批次、划拨移到明细子页面。团队内保留升级与绑定门店。中央 capability 注册仍完整，最高权限不再等于平铺所有路由。
- 甄选五类目录、标准/活动/会员价格、商品详情、规格库存与数量、购买入口；商品封面复用用户原切图 `demo-product-cover.png`，运行文件改为 `static/product/product-cover.png`，五类共用此封面属于 Mock 数据。
- 确认订单支持所属门店、收货地址、会员、优惠券、备注和询价；使用底部选择面板。实物必须有地址，特色产品和行政费必须选择会员。
- 收银台有支付方式及服务端时间偏差倒计时；Mock 支付经过 attempt 创建与查询才改变订单。软件卡、专栏支付不等于激活；实物支付进入待发货；线下服务提示到店履约。
- 我的订单与个人中心数量同步；补充待付、取消、待发货、待收货、完成数据。支持取消、确认收货、订单编号复制及对应动作限制。门店查看订单传递经营上下文，详情只读。
- VIP购买、年度权益接入同一收银台，支付查询后才增加 Mock 名额/年度权益，幂等处理不会重复增加。
- 专栏购买、激活、目录和课程阅读；会员学习增加图文/视频课程阅读，保留会员与课程授权校验，等级权益正文依旧为空。
- 健脑官工作台、门店会员资料、课时/备注编辑、训练反馈列表和发布、反馈详情；上传图片、MP4、PDF。课时变更同步到家长会员列表；总课时与消耗校验、版本冲突、重复发布均有防护。
- 转店地区/关键词筛选、选择门店、原因和二次确认，取消不写入；提交后进入原门店待办审批。审批状态变化不代表真实组织/合同已变更。
- 本地推广二维码、导出预览、代理申请入口、地区/门头照/费用信息、提交待审核及我的申请。未登录代理申请保留白名单邀请参数，登录后返回申请页。普通分享码复用二维码组件。
- 取消业务页面中重复的“测试/演示”说明和按钮前缀。错误、加载、缺少必要资料等正常业务提示继续保留。

## 代码与替换约定

`src/services/mock/commerce.js`、`training.js`、`agency-application.js` 及既有 Mock 文件统一标注 `TODO(API)` / `MOCK-ONLY`。价格、佣金、支付、库存与组织关系只在 Mock 中模拟。页面调用 `services/commerce.js`、`training.js`、`agency-application.js`、`training-assets.js`、`lesson.js`，禁止真实 API 失败回退假成功。

当前目录注册69条页面路由；全部文件及52个静态资源字面量引用存在。原任务卡 `store/staff`、`store/members`、`store/approvals`、`store/edit` 四条建议路由合并在 `store/index` 的标签/弹窗中，并非独立文件。

Mock 商城和经营余额有账户隔离的本地测试缓存：`naoshang-mock-commerce-v1:*`、`naoshang-mock-business-v2:*`。接入 API 时应迁移/删除这些数据键及整个 Mock 适配器。训练反馈和本地上传预览目前在运行内存中，刷新后可能重置；临时 blob/小程序文件不作为永久媒体地址。

订单与支付的恢复数据不是可随意删除的演示提示：`naoshang-checkout-intent:*`、`naoshang-payment-intent:*` 保存未确认结果的原 quote/key/attempt，接入真实接口时须保留等价恢复机制。创建订单结果未知时锁定原意图并复用 key；明确400/422拒绝或约定409业务代码才释放重新询价。支付处理中保留 attempt 供查询，不能换渠道重新创建。

新增 `qrcode@1.5.4` 仅用于编码实际本地测试链接，不使用设计稿静态二维码替代业务二维码。当前本地邀请链接以 `http://localhost:5173` 开头，仅供当前开发环境；正式域名、邀请签名、失效与分享载荷需后端提供，不能直接发布此链接。二维码字节编码避开小程序缺失 TextEncoder 的风险，保留四模块安静区。

示例专栏码：购买完成后使用 `NS-COLUMN-2026`。会员激活仍沿用 `DEMO-L1` 至 `DEMO-L10`。示例视频来自 MDN CC0 flower.mp4，用于播放控件检查，后续替换成受授权课程媒体；素材/等级权益富文本没有因此填充内容。

## 正式接入边界

本轮完成的是可交互前端与 Mock 业务链。远端接口和 DTO 均为 proposed：catalog、checkout/options、quotes、orders、payments/attempts、columns、coach/workspace、training-feedback、store-transfer/options/applications、agency/applications 等必须与后端统一。真实支付 SDK 尚未适配；当前真实分支保留已创建的支付 attempt 并提示/查询，不能视作可线上收款。真实佣金、审核生效、课时审计、永久媒体与法务协议仍需后台实现和联调。

上传视频/PDF当前限定30MB、MP4/PDF，属于客户端提案；真实限制由后端返回并校验。远端媒体仅接受HTTPS；小程序PDF先下载再打开，H5打开经过适配的地址。图片/视频/文件上传及二维码相册导出尚未完成真机权限验证。

没有提交到远程仓库、部署、实际付款或实际开通任何身份；页面内不额外显示测试标签不改变上述开发边界。
