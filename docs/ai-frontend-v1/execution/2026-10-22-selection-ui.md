# 设计120：甄选布局与会员价浮层修正

本批核对原图120及蓝湖导出 lanhu_120zhenxuan，覆盖上一批价格区域样式。

- 会员价使用按钮锚定的上浮提示框，包含边框、向下箭头、档位/折扣/金额及当前档位高亮，不调用 showModal。页面同时只打开一个；重复点击、页面空白、切换分类、触摸滚动或 Escape 收起。
- 标准/活动/会员价三列等宽，数字与标签纵向居中；整数金额去掉无意义的 .00。行政费按图120仅显示通栏标准价。
- 右侧恢复单列纵向商品布局，保留小图、商品名称与单行省略简介；移除图稿外的“查看商品”按钮，点击商品仍进入详情。初始“全部分类”展示各商品区段，其他分类可以筛选。
- 页面底色#26376b、侧栏#364a84、页头#1e3164、价格卡#465583、浮层#0c2650、价格文字#59b6ff从设计图/导出样式核对；尺寸用相对单位、网格和百分比，未复制固定整页高度。
- Mock 增加展示元数据 pricePresentation、memberPrices[].discountLabel/current；正式适配层应由服务端返回，客户端不计算折扣或从权限角色推断价格档位。

验证：商城15项回归测试通过；H5、mp-weixin构建通过。浏览器检查320、375、812宽度；320三列实测等宽63px，浮层位于按钮上方且未超出视口；812保持单列商品布局。验证了切换浮层、再次点击与Escape收起。小程序真机尚未检查。
