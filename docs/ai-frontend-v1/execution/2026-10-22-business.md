## 本批功能

批发商工作台展示 16 个入口：收益、上级、推广码、素材、全球分红、推广任务、体验官、团队、额度流水、转让记录、额度批次、额度转让、购买额度、会员升级、年度权益、绑定门店。已有素材库继续复用。上级关系和推广任务当前只读；推广码没有后台 payload 时显示空态。

合店老板支持三个测试合同门店切换、合店收益、会员卡分红和推广分红。收益、分红、钱包按账户和合同上下文隔离。九列表格在自身容器横向滚动。

区域代理支持单店、区县、市代、省代四类测试身份切换、团队逐级下钻、收益及分配详情、门店管理。门店管理合并为健脑官、合店老板、会员、审批四个标签；包含健脑官新增与编辑、门店基础资料编辑、申请同意/拒绝及拒绝原因校验。会员只读，不含课时调整或正式转店执行。

交易类操作采用 options → quote → commit；包含受益人确认、版本、有效期、幂等键校验。额度购买和年度权益只生成待支付结果，不产生支付成功或额度到账；提现仅进入测试待审核；提点分配后进入待结算，不增加可提现金额。金额请求使用整数分。

业务时间统一按上海时区显示。详情采用自定义返回头，修复直接刷新详情后返回首页误入登录的问题。异步页面卸载后丢弃旧响应，账户或 token 变化时拒绝旧请求结果。

## 文件与路由

- `src/features/business/catalog.js`：入口注册、权限和路由。
- `src/components/Business*.vue`：工作台、报表、团队、收益详情、操作、提现记录、门店管理等共享组件。
- `src/services/business*.js`：上下文校验与 proposed 真实适配层。
- `src/services/mock/business*.js`：按账户及上下文隔离的测试数据与操作。
- `src/styles/business.css`：响应式业务布局。
- `src/pages/{partners,partner,costore,agency,store,income,wallet}/`：页面入口；准确注册以 `src/pages.json` 为准。
- `tests/business.test.cjs`：9 项业务测试。

原任务卡的门店子页面部分合并到 `/pages/store/index` 标签页，不能据此声称所有建议路径都已实现。

## 后续接入与未完成范围

所有远端契约仍为 proposed，需后端确认。新增适配假设包括 `/me/bootstrap.businessContexts`、`/costore/overview`、`/agency/store-workspace`、操作 options/quotes 及 `/wallet/withdrawal-quotes` 等聚合接口。报表内部 DTO 使用 metrics/columns/items/hasMore/nextCursor；不得认为原 API 清单已经支持这些字段。

真实支付、支付回调、正式提现及新收款账户维护、佣金规则、分红资格与奖池计算、额度活动和有效期、正式年度权益、上级绑定、推广任务写入、推广码生成与分享、门店转让及教练课时维护仍需开发或联调。当前审批不执行真实合同、付款或组织关系变更。不同收入类别当前复用通用详情，尚未逐个复刻全部类别的差异页面。

Mock 业务状态在内存中，刷新或热更新会重置；本地仅保留已校验的上下文选择。测试身份不是正式授权。上线时关闭测试展示，并由服务端验证每次读取和写入的账户、合同、代理归属和 capability。
