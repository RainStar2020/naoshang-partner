## 1. 范围与优先级

1. **后台只供总部人员**。门店老板、店长、健脑官、区域代理、合伙人不因此获得后台资格。同一账号若兼业务身份，仍须单独校验总部授权。
2. **小程序保留业务工作台**：门店审核、健脑官管理、合伙人划拨/升级、合店申请、代理申请、提现申请等仍在 C 端完成；后台做查询、配置、监管、异常干预，不复制个人购买/提现/二维码上传工作台。
3. **冲突优先级**：用户确认与业务规则 > 方案表/附件 > 旧文档与 Mock。附件（如《脑商合伙人方案简版》）仅作业务资料。
4. **金额**：当前 Mock/页面多用**整数分**；联调前须与后端冻结单一单位（见 API 需求文档）。`rateBps` 为万分比。
5. **不做本期**：通用退货退款换货、排课考勤考试证书、复杂促销、BI 大盘。合店拒审退款为明确例外。客服入口保留、实现后续。
6. **状态标注**（下表「前端现状」列）  
   - **已实现**：页面与服务调用齐全，可在 Mock 下演示完整流程  
   - **Mock**：依赖 `config.useMock` / 契约 Mock，未接真 API  
   - **缺口**：路由/能力未齐、或仅有入口无完整联调、或明确待后端

## 2. 领域规则（前后台共同遵守）

### 2.1 账号、孩子与经营身份

- **Account** = 登录账号/家长；**Member** = 账号下的孩子/学员。ID 不可混用。
- 孩子学习身份只影响会员学习；联营操作、合伙等级、代理/合店身份属于**账号**，不继承当前选中孩子。
- 商品订单购买人始终为账号；学员关联仅作服务交付参考。
- 同一账号可有多个代理任职（独立 `assignmentId`）；合店用独立 `contractId`。
- 区域代理同级独占（至少同区县一个有效县级代理）；并发占位由后端负责。

### 2.2 学习会员与年度权益

- 激活某一**会员等级**后，其包含的全部学习等级自动解锁；禁止按学习等级单独收费或重复激活。
- 学习会员权益**永久有效**；总部可人工开通/撤销/补发，须可追溯。
- 年度经营权益（如 200 元/年）有效一年；到期不影响学习权益。是否向下包含其他会员等级由后端配置，前端只展示授权结果。
- 购买成功 ≠ 课程/专栏开通：联系门店拿激活码，用户主动激活。
- **软件卡发码**与**课程/会员激活码**为独立系统，输入一类码不得打开另一类权益。
- 专栏允许多次购买（含已解锁）；不可因 `unlocked` 禁下单，也不可因复购重置进度。专栏复用会员课程的进度逻辑，数据按账号/专栏隔离。

### 2.3 合伙等级、晋升与名额

- 小批 / 中批 / 大批 / 总批 ↔ VIP / 天使 / 秘籍 / 联创。
- **名额消耗升级**：等级累计占用 1 / 3 / 6 / 24；所需消耗 = 目标占用 − 当前占用。报价与扣减由 API 负责。
- **直推任务晋升**：一年内达三个本级直推折算目标后，用户点按钮请求 API；**禁止页面加载时自动晋升**。进度 `x` 来自 API（VIP→天使 x/3，天使→秘籍 x/9，秘籍→联创 x/18）；联创无下一档。
- 「1 联创 = 4 秘籍 = 8 天使 = 24 VIP」是体系描述，**不是**另一套扣减公式。
- 非任务升级由介绍人（直属上级）消耗名额办理；总部可人工升级。小程序不能自行补价升级、不能给非直属下级改等级。
- 标准购买名额永久有效；活动赠送名额永久有效但不可转让、不可退款。活动名额升级另付服务费（演示口径每名额 2000 元），付款前不生效。
- 总部充值仅限获特定权限的联创；联创身份本身不自动等于充值资格。

### 2.4 交易与审批

- 商品仅一级分类；展示标题可改，机器业务编码与履约策略保持稳定。
- 优惠券一单仅一张，不叠加；订单保留原价/成交价/券快照。
- 软件卡、线下服务、专栏默认可由所属门店交付；总部可改交付方。
- **合店**：创建付款订单 → 支付成功 → 门店老板审核 → 通过后更新合同/权益；拒绝后发起退款，等回执。拒绝 ≠ 已退款。
- **转店**：双边审核；任一方拒绝不迁移；双方同意后由 API 做归属迁移。
- 总部可解绑/换绑上级，不改写历史收益；注册时邀请码建立初始关系仍保留。

## 5. 总部功能要点（按编号，与第 3 节对照）

以下为已确认范围摘要；字段与验收细节以实现时 API 契约为准。

### HQ-01～03 账号与会员档案

- 总部登录与内部角色（运营/财务/超管划分待定）；拒绝「仅有业务身份」的账号进后台。  
- 按手机/账号/昵称/地区/状态/门店查用户；冻结、解冻、重置密码；改所属门店并记前后门店与原因。  
- 孩子档案查询；人工开通/撤销/补发会员权益（补发是重发码还是直接恢复须可区分）。

### HQ-04～08 内容与激活

- 会员等级、学习等级归属、章节图文/视频 CMS；同等级内解锁状态一致。  
- 激活码批采、发放、作废、导出；关联目标等级或专栏。  
- 软件卡发码为**独立系统**，不得与课程码串权。  
- 专栏可复购；进度按账号/专栏隔离。  
- 公告发布与已读统计。

### HQ-09～13 商品、订单、支付

- 一级分类 + 商品类型 + SKU；报价不采信页面折扣标签文案。  
- 交付默认：所属门店 / 总部；可改单并记原因。  
- 订单查询与履约；`allowedActions` 由 API 给出；非实物支付成功 ≠ 已交付/已激活。  
- 优惠券模板与发放；一单一次占用。  
- 支付渠道按小程序/H5；查单、对账、异常补单；密钥与回调在服务端。补单须先向渠道核验再业务补账。

### HQ-14～18 合伙、名额、合店、代理

- 合伙档、年度权益、晋升任务进度只读 API；总部手动升级留痕。  
- 名额批次/流水；标准与活动分类；总部向获权联创充值。  
- 邀请上下级查询；总部解绑/换绑介绍人；禁止用户自助换绑。  
- 合店：先付后审；总部监管不替代门店日常审批；拒审退款状态分处理中/成功/失败。  
- 代理：多任职、区域独占、费用方案（方案表金额仅供参考，实收以 API 报价为准）。

### HQ-19～21 门店与训练

- 门店主档、归属代理、门头照、合店费用边界、员工任职查询。  
- 健脑官账号由门店在小程序创建/改密；总部监管；Mock 只存 `credentialSet`。  
- 反馈代写/撤回；课时逐次核销流水；禁止负库存或超余量；版本冲突刷新。  
- 转店双边待审 → 双方同意后服务端迁移；单方同意仍待审。

### HQ-22～26 收益、提现、素材、协议、审计

- 收益跨账号/门店/区域联查；改分配、结算、重算、冲正不直接覆盖历史，关联原流水。公式与比例一律后端计算。  
- 提现审核与凭证；最低额/费率/人工或自动打款**待定**（勿照搬 Mock 示例）。  
- 素材：原图框选唯一二维码填充区；用户只上传码；服务端合成。视频走互动 H5，不默认烧录二维码；当前无专用 web-view 路由，属联调增量。  
- 协议版本管理；客服后续。  
- 通用上传资源与操作追溯支撑各模块。

## 6. 本轮 API / 联调要求（与小程序相关）

1. 生产构建禁止默认 `useMock` / 双 preview；建议环境变量 + CI 断言（见 Mock 说明文档）。  
2. 鉴权：接真后 bootstrap / `/me` 校验；支付、提现、划拨、晋升以服务端为准，本地 session 仅缓存。  
3. 金额单位、幂等键（下单、支付、划拨、核销、发券）在契约层统一。  
4. `capabilities` / `businessContexts` 由后端下发；前端隐藏菜单不能代替鉴权。  
5. 合店未知提交结果须持久原报价、协议版本、请求号；同报价不得换请求号重复创建付款。  
6. 转店与跨门店迁移由后端执行；前端只反映审批状态，不伪造已迁移。

## 8. 前端真实能力边界（2026-10-27）

### 8.1 小程序侧已具备（Mock 可演示）

- 四 Tab 信息架构与约 69 条路由  
- 学习会员浏览/激活演示、公告、专栏与商城下单链路  
- 联营三模块工具目录与多数经营页（收益、团队、名额、升级、素材等）  
- 合店/代理申请、门店与健脑官、反馈与转店状态机  
- 提现申请/列表、优惠券、地址、协议与反馈入口  
- 能力目录与 preview 闸门、富文本节点白名单、回跳白名单、部分契约单测

### 8.2 仍依赖真实后端 / 总部后台

- 总部 React/Vue 管理端尚未在本仓库建设（旧文档曾写 `naoshang-front-react`，**已更正为本 uni-app 映射说明**；后台技术选型另定）  
- 真实支付、退款、结算、晋升生效、冻结、人工权益、发码、代理独占并发  
- 对账、补单、打款凭证、跨账号审批数据一致性  
- 素材视频 H5 与统一操作审计台

### 8.3 建议验收顺序

1. 账号冻结/门店归属 → 小程序登录与资料刷新  
2. 会员等级 CMS + 激活码 → 学习页解锁一致  
3. 商品报价/券/下单 → 收银台查单  
4. 合伙升级与名额划拨 → 流水与权限  
5. 合店付费审批与拒审退款  
6. 代理独占与多任职  
7. 转店双边与迁移  
8. 收益结算/冲正与提现审核  

每项验证：**总部写入 → API 状态 → 小程序刷新**，并覆盖无权限、版本冲突、未知结果重试、身份隔离。
